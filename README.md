# EduGenie - AI Learning Assistant

EduGenie is an AI-powered learning assistant designed to help students
understand topics, ask questions, generate quizzes, summarize study
materials, and create personalized learning paths.

## Features

- Ask questions and get AI-powered answers
- Explain topics in simple language
- Generate quizzes
- Summarize study material
- Generate structured learning paths
- Gemini-powered AI responses
- Optional local AI explanation module

## Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- JavaScript
- Jinja2
- Transformers
- PyTorch
